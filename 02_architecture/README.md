# 第二章：Harness 架构全景

本章从架构设计层面全面剖析 Harness 系统。

首先提出一个通用的参考架构（三层 + 横切关注点）。不同 Harness 实现的名称和细节各有差异，但都能在这一架构中找到对应的概念，核心的分层思想是一致的。

接着讨论每一层的设计原则、职责范围和接口规范，并对比三个业界参考实现（OpenAI Codex 的性能型架构、Claude Code 的任务型架构和 OpenClaw 的自驱型架构），展示不同应用场景下的架构取舍。

随后讨论安全性和可观测性两个横切关注点。它们不是独立的层，但贯穿系统各处，直接影响系统的可靠性。

最后通过 MiniHarness 项目的脚手架搭建，把上述概念转化为可运行的代码，加深读者对架构的理解，并为后续的系统开发打下基础。

本章承接第一章的概念，为后续各章的深入设计提供架构框架。

- 2.4：层间接口设计
