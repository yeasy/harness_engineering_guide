# 第一章：Harness 工程概论

本章定义并剖析 Harness 工程这一核心概念，为全书建立基本认识。

本章从智能体原理的简要回顾出发，说明在大语言模型时代系统工程能力为何比模型能力本身更关键。借助“驾驭”这一比喻，本章阐明 Harness 的作用：它不增强智能体的思考能力，而是用约束、可验证性和层次化的信任机制，让智能体在复杂、真实的环境中安全可靠地执行任务。

随后介绍 Harness 工程的五大核心子系统和两大基础保障，并对比两个业界领先的参考系统（Claude Code 和 OpenClaw），展示不同的架构选择如何应对不同的使用场景；后续章节还会引入 Codex 等参考系统作为扩展对照。最后介绍实战项目 MiniHarness，读者将借助它从零构建一个完整的 Harness 系统。

本章建立的基础概念贯穿全书，后续各章均在此基础上展开。
