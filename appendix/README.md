1. **快速查询**：遇到陌生概念时，使用附录 A 术语表快速查找定义
2. **深度学习**：想了解某个主题的前沿研究时，参考附录 B 的论文列表
3. **实践参考**：需要工具或框架推荐时，查看附录 C 的资源汇总
4. **代码学习**：理解具体实现时，通过附录 D 定位 MiniHarness 相关代码
